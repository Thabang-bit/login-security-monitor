# Login Security Monitor

A beginner-friendly Python cybersecurity project that analyzes login logs and detects possible brute-force attacks.

## Features

- Reads login activity from a log file
- Counts failed login attempts
- Detects users with multiple failed attempts
- Displays a security warning

## Technologies

- Python
- Git
- GitHub

## How to Run

Run the program with:

```bash
python3 security_monitor.py
